# Արմատ: правила работы с проектом

## Назначение

Արմատ — личный русскоязычный тренажёр для изучения армянского алфавита. Это статичное офлайн-приложение: не добавляйте бэкенд, учётные записи, базу данных или внешнее хранилище без явного запроса пользователя.

Перед началом любой задачи прочитайте `memory-bank/product.md`. После изменений, затрагивающих продукт, UX, архитектуру или принятые решения, обновите этот файл в рамках той же задачи.

## Архитектура и данные

- `dist/index.html` содержит весь интерфейс, стили и клиентскую логику.
- `dist/alphabet.json` — расширяемый источник изученных букв при запуске через локальный веб-сервер.
- `.openai/hosting.json` публикует статическую папку `dist`.
- Формат каждой записи алфавита неизменен: `{ "upper": "Ա", "lower": "ա", "sound": "А" }`. Добавляйте буквы новыми записями, не меняя имена полей.
- В `index.html` есть `starterAlphabet` для открытия файла двойным щелчком. При изменении `alphabet.json` синхронно обновляйте этот встроенный набор.

## Поведение интерфейса

- На главном экране карточка обязана явно показывать выбранное и невыбранное состояние.
- Тренировка показывает случайную букву из выбранных и четыре варианта произношения, среди которых ровно один правильный.
- После ответа показывайте цветовую обратную связь; при ошибке отдельно подсвечивайте правильный вариант.
- Порядок вопросов и вариантов ответа должен оставаться случайным.
- Сохраняйте интерфейс русскоязычным, простым и пригодным для мобильного экрана.

## Проверка перед завершением

Проверьте, что:

1. Буквы загружаются из JSON при запуске через веб-сервер, а встроенный набор работает при открытии `index.html` напрямую.
2. Карточки можно выбрать и снять выбор; кнопка тренировки корректно реагирует на это состояние.
3. Верный и неверный ответы дают ожидаемую подсветку, а серия завершается результатом.
4. Интерфейс не обрезается и остаётся управляемым на узком экране.
