# Состояние продукта: Արմատ

Последнее обновление: 30 сентября 2026

## Назначение и аудитория

Արմատ — личное русскоязычное веб-приложение для начального изучения армянского алфавита и грамматики. Оно рассчитано на короткие самостоятельные занятия.

## Текущее состояние

- В разделе «Буквы» доступен полный набор из 39 букв: Ա, Բ, Գ, Դ, Ե, Զ, Է, Ը, Թ, Ժ, Ի, Լ, Խ, Ծ, Կ, Հ, Ձ, Ղ, Ճ, Մ, Յ, Ն, Շ, Ո, Չ, Պ, Ջ, Ռ, Ս, Վ, Տ, Ր, Ց, Ու, Փ, Ք, Եվ, Օ, Ֆ. «Урок 1» относится к разделу «Грамматика».
- На главном экране пользователь выбирает нужные карточки по одной или одной кнопкой выбирает либо снимает выбор со всех карточек.
- Тренировка задаёт вопрос по каждой выбранной букве, предлагает четыре варианта и показывает результат ответа.
- Добавлен раздел «Грамматика» с «Уроком 1 — Множественное число существительных». Четыре блока охватывают основное правило -եր / -ներ, изменение основы, особые случаи с -ներ и нерегулярные формы. Учебный материал взят из предоставленного документа «Урок 5»; номер документа не определяет номер в приложении. Лексика о семье в приложение не включена.
- Любой блок можно открыть сразу. Его практика задаёт до шести случайных вопросов с двумя вариантами ответа; смешанная тренировка задаёт 12 вопросов — по три из каждого блока. После ответа показываются правильная форма и пояснение, после результата можно повторить ошибки.
- Прогресс, статистика и пользовательские данные не сохраняются между открытиями страницы.

## Принятые решения

- Приложение статичное: без бэкенда, учётных записей, базы данных и внешнего хранилища.
- `dist/alphabet.json` — источник данных для расширения алфавита при запуске через локальный веб-сервер.
- В `dist/index.html` хранится синхронный стартовый набор, чтобы приложение работало и при открытии файла двойным щелчком, когда браузер не даёт прочитать соседний JSON.
- Шрифты Onest и Noto Serif Armenian с лицензиями хранятся в `dist/fonts` и подключаются локально. Для работы страницы не требуются внешние запросы.
- `scripts/check-data.mjs` проверяет соответствие двух наборов букв, уникальность произношений и неверные варианты ответов в грамматических примерах.
- `dist/grammar-lessons.js` содержит данные грамматических уроков и подключается обычным `<script>`, поэтому работает через веб-сервер и при открытии HTML-файла напрямую. Следующие уроки добавляются в тот же массив данных по схеме «урок → блоки → примеры и варианты ответа».
- Номера грамматических уроков выводятся автоматически по порядку объектов в массиве: первый — «Урок 1», следующий — «Урок 2». Подпись номера не хранится в данных урока.
- Формы, переводы, правила и исключения переносятся из предоставленного урока без самостоятельных исправлений и дополнительных сведений. Текст объяснения можно сокращать и переформулировать без изменения смысла; предполагаемые ошибки обсуждаются с пользователем до правки.
- Карточки букв выводятся в современном армянском алфавитном порядке; новые записи добавляются на свою алфавитную позицию одновременно в JSON и во встроенный набор.
- Интерфейс и документация проекта ведутся на русском языке.
- Бренд продукта отображается как «Արմат»; название репозитория и публичный адрес используют латинское `armat`.
- Репозиторий: `https://github.com/valkinaz/armat`. GitHub Actions настроен на публикацию `dist` на GitHub Pages после каждого пуша в `main`; доступность сайта проверяется отдельно. `.openai/hosting.json` задаёт папку `dist` для хостинга Codex.

## Следующие идеи

Следующие грамматические уроки могут использовать ту же последовательность: объяснение, примеры, практика, результат и повторение ошибок. Содержание уроков и новые типы заданий требуют отдельного запроса.
