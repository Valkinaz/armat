# Product context

## Что такое Արմատ

**Արմատ** — личный русскоязычный тренажёр для изучения армянского языка.

Проект появился как способ закреплять материал между занятиями армянским короткими сессиями примерно по 5–7 минут. Вместо попытки создать полноценное приложение для изучения языка Արմատ решает конкретные учебные задачи по мере их появления.

Проект развивается вместе с процессом обучения: сначала появился тренажёр армянского алфавита, затем начали добавляться грамматические уроки и связанные с ними упражнения.

Название **Արմատ** по-армянски означает «корень» и отражает идею изучения языка с основ.

## Для кого проект

Основной пользователь — автор проекта, изучающий армянский язык с русским как основным языком объяснений.

Արմատ не проектируется как универсальная образовательная платформа для широкой аудитории. При выборе между универсальностью и удобством для реального процесса обучения приоритет отдаётся последнему.

Это позволяет добавлять функции тогда, когда возникает практическая учебная потребность, а не заранее строить возможности, которые могут никогда не понадобиться.

## Основная модель продукта

В приложении есть два основных направления обучения:

### Алфавит

Раздел предназначен для изучения и закрепления армянских букв.

Пользователь может работать с армянским алфавитом и тренировать выбранные буквы, сопоставляя их с произношением.

Тренировка должна подходить как для первоначального знакомства с буквами, так и для быстрого повторения уже изученного материала.

### Грамматика

Грамматика организована в виде отдельных тематических уроков.

Урок состоит из небольших смысловых частей и сочетает:

- краткое объяснение правила;
- примеры;
- практику конкретной части темы;
- общую тренировку материала урока;
- возможность повторить задания, в которых были допущены ошибки.

Такой формат позволяет сначала разобрать тему небольшими частями, а затем проверить понимание материала целиком.

Новые грамматические темы добавляются по мере их прохождения на занятиях армянским.

Практика зависит от материала урока. Для множественного числа существительных пользователь выбирает правильную форму слова. В уроке о вспомогательном глаголе в настоящем времени есть утверждение, отрицание, конструкции «Это…» и вопросы. В каждом блоке отдельно запускаются выбор формы глагола в предложении и сборка предложения из готовых слов; смешанная тренировка объединяет оба формата.

Сборка проверяет воспроизведение конкретного образца урока. При другом порядке слов приложение сообщает об отличии от образца, не объявляя любой другой порядок грамматической ошибкой. Регистр и пунктуация уже включены в слова. До проверки можно вернуть слово или сбросить сборку; после проверки результат фиксируется. Повторение ошибок сохраняет тип задания и выбранный образец.

Разговорные альтернативы из материала показываются с явной пометкой. В выборе формы принимаются все указанные допустимые ответы, а для сборки разговорной фразы используется отдельный помеченный образец.

Данные уроков хранятся в TypeScript-модулях: примеры предложений служат общим источником текста, перевода и пояснения для заданий обоих типов. Алфавит хранится в одном JSON-источнике. Приложение и проверочный скрипт используют одни и те же учебные данные.

## Архитектура и навигация

Приложение использует React, TypeScript и Vite, оставаясь статическим клиентским приложением без backend и базы данных. Исходники отделены от результата сборки; локальный запуск требует HTTP-сервера разработки или preview. Поддержка открытия HTML напрямую с диска отсутствует.

Разделы, уроки и блоки имеют прямые адреса без `#`, которые обрабатывает React Router с BrowserRouter. Ссылка на блок открывает полный урок и переводит прокрутку и фокус к выбранному блоку. Материалы доступны через обычные ссылки, в том числе для открытия в новой вкладке. Неизвестный адрес показывает экран «Материал не найден».

Тренировки не имеют публичных адресов. Запуск практики добавляет запись истории с прежним URL материала и идентификатором сессии. Вопросы, ответы и результат меняют внутреннее состояние, не добавляя записей истории.

Выбор букв и одна активная тренировка хранятся только в памяти вкладки. Переход в другой раздел и возврат по истории восстанавливают занятие, включая выбранные слова, порядок вариантов, ответ и результат. Новая тренировка заменяет предыдущую. Повтор ошибок продолжает ту же сессию с новой очередью из ошибочных заданий.

После перезагрузки страницы, открытия ссылки в новой вкладке или возврата к заменённой сессии открывается исходный материал. Занятие нужно запустить кнопкой. Прогресс не записывается в браузерное хранилище и не синхронизируется между устройствами.

## Принципы UX

### Короткие занятия

Типичный сценарий использования — открыть приложение на несколько минут и повторить конкретный материал.

Для начала тренировки не должно требоваться длительной настройки или прохождения лишних экранов.

### Сначала объяснение, затем практика

Новый материал должен давать пользователю достаточно контекста, чтобы понять правило или закономерность до начала проверки знаний.

Практика дополняет объяснение, а не заменяет его.

### От простого к смешанному

Если тема состоит из нескольких отдельных правил или случаев, пользователь должен иметь возможность сначала потренировать их независимо друг от друга, а затем пройти смешанную тренировку.

### Ошибки должны помогать повторению

Ошибочный ответ не должен быть тупиком. Пользователь должен понимать правильный вариант и иметь возможность отдельно вернуться к материалу, в котором ошибался.

### Минимум лишней сложности

Интерфейс должен оставаться простым и сосредоточенным на самом упражнении.

Новые механики, экраны и элементы интерфейса добавляются только тогда, когда они решают конкретную учебную задачу.

## Принципы учебного контента

Учебный материал является основной частью продукта и требует такой же аккуратности, как программный код.

При добавлении или изменении материала важно сохранять согласованность между:

- формулировкой правила;
- объяснением;
- примерами;
- заданиями;
- правильными ответами.

Армянские формы и правила не следует изменять как побочный эффект технического рефакторинга.

Объяснения предназначены для начинающего русскоязычного ученика, поэтому предпочтительны короткие и практичные формулировки без избыточной лингвистической терминологии, если она не помогает понять тему.

## Границы продукта

Արմատ не ставит целью заменить учебник, преподавателя или полноценный курс армянского языка.

Также нет цели заранее реализовать все возможные типы упражнений или охватить всю грамматику.

Продукт растёт итеративно:

1. появляется реальная учебная задача;
2. определяется удобный способ её тренировать;
3. этот сценарий добавляется в приложение;
4. дальнейшее усложнение происходит только при новой практической необходимости.

Поэтому существующий формат упражнения или урока является текущим продуктовым решением, но не должен автоматически восприниматься как ограничение для всех будущих типов учебного материала.
