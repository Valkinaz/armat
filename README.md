# Արմատ — тренажёр армянского языка

**Արմատ** — небольшой русскоязычный тренажёр для изучения армянского языка.

Проект появился как личный инструмент для коротких занятий между уроками армянского. Хотелось иметь простой способ за несколько минут повторить буквы, закрепить новую тему или немного потренироваться — без полноценного учебного приложения и лишней сложности.

Со временем тренажёр растёт вместе с тем, что я изучаю: всё началось с армянского алфавита, а теперь в нём есть тематические наборы слов и грамматические уроки.

### [Открыть Արմատ](https://armat.valkinaz.com/)

## Что есть сейчас

- армянский алфавит с заглавными и строчными буквами;
- тренировка произношения выбранных букв;
- тематические наборы слов и выражений с тренировкой перевода в обе стороны;
- совместная тренировка нескольких наборов: до 20 вопросов или полный проход;
- грамматические уроки с правилами и примерами;
- отдельная практика по блокам урока;
- выбор формы глагола и сборка предложений по образцу;
- смешанная тренировка по всей теме;
- возможность повторить задания, в которых были ошибки.

## О проекте

Արմատ — статическое веб-приложение без бэкенда и базы данных. Код проекта использует React, TypeScript и CSS.

Проект развивается по мере изучения языка, поэтому новые темы и форматы тренировок появляются тогда, когда в них возникает практическая необходимость.
