# Արմատ — армянский алфавит и грамматика

Это статичное русскоязычное приложение для коротких самостоятельных занятий. В разделе «Буквы» можно выбрать буквы и проверить их произношение. В разделе «Грамматика» доступен урок о множественном числе существительных с объяснениями, примерами и тренировкой.

## Открыть приложение

Самый простой вариант — открыть [dist/index.html](dist/index.html) двойным щелчком. Набор из 39 букв встроен в страницу, а данные грамматического урока подключаются из соседнего `grammar-lessons.js`. Шрифты хранятся в `dist/fonts`, поэтому оба раздела работают без интернета, бэкенда и базы данных. Прогресс между открытиями страницы не сохраняется.

Чтобы приложение читало изменения из `dist/alphabet.json`, откройте папку `dist` через любой простой локальный веб-сервер. Например, если установлен Python, в корне проекта выполните:

```powershell
python -m http.server 4173 --directory dist
```

Если в Windows доступна команда `py`, вместо `python` можно использовать её. После запуска перейдите по адресу `http://localhost:4173`.

## Публикация в интернете

Для проекта настроена публикация через GitHub Pages по адресу [valkinaz.github.io/armat](https://valkinaz.github.io/armat/). Доступность сайта нужно проверять отдельно.

Workflow `.github/workflows/deploy-pages.yml` публикует папку `dist` после `git push` в `main`. Файл `.openai/hosting.json` задаёт ту же папку для хостинга Codex; сам по себе он не запускает публикацию на GitHub Pages.

## Проверка данных

При изменении букв или грамматических примеров выполните `node scripts/check-data.mjs` из корня проекта. Скрипт проверяет совпадение JSON со встроенным набором букв, уникальность вариантов произношения и отличие неверного ответа от правильного в каждом грамматическом примере. Node.js нужен только для этой проверки, не для запуска приложения.

Локальные шрифты Onest и Noto Serif Armenian поставляются с лицензиями в `dist/fonts`.

## Добавить букву

Отредактируйте `dist/alphabet.json` и добавьте запись в том же формате:

```json
{ "upper": "Բ", "lower": "բ", "sound": "Б" }
```

`upper` и `lower` — заглавная и строчная формы; `sound` — произношение, которое будет показано на карточке и в вариантах ответа. Добавляйте запись на её место в современном армянском алфавитном порядке и одновременно обновляйте `starterAlphabet` в `dist/index.html`, чтобы набор работал и при открытии файла двойным щелчком. После сохранения обновите страницу браузера.

## Грамматические уроки

«Урок 1 — Множественное число существительных» состоит из четырёх блоков: основное правило **-եր / -ներ**, изменение основы, особые случаи с **-ներ** и нерегулярные формы. Блоки можно открывать в любом порядке. Каждый содержит объяснение и примеры из предоставленного материала; практика выбирает до шести слов случайно. Смешанная тренировка задаёт 12 вопросов — по три из каждого блока. В каждом вопросе два варианта ответа, затем показываются правильная форма и пояснение. После результата можно повторить слова, в которых были ошибки.

Данные уроков находятся в `dist/grammar-lessons.js`. Для следующего урока добавьте в конец массива `window.grammarLessons` новый объект с уникальным `id`, названием `title`, описанием `lead` и блоками `blocks`. Номер выводится автоматически по порядку объектов: первый — «Урок 1», второй — «Урок 2». Название исходного документа не определяет номер в приложении. Каждый блок содержит `id`, `title`, `rule`, `detail` и `examples`; для каждого примера нужны `singular`, `plural`, `wrong`, `ru`, `note`. Поле `wrong` должно содержать ответ, неверный именно для данного слова и отличный от `plural`. Формы, переводы, правила и исключения переносите из предоставленного урока без самостоятельных исправлений и дополнительных сведений; пояснения можно сокращать без изменения смысла. Данные доступны и через веб-сервер, и при открытии файла напрямую.
