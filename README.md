# Արմատ — тренажёр армянских букв

Это статичное приложение: бэкенд и база данных не нужны.

## Открыть приложение

Самый простой вариант — открыть [dist/index.html](dist/index.html) двойным щелчком. Начальный набор из 12 букв уже встроен, поэтому тренировка заработает сразу.

Чтобы приложение читало изменения из `dist/alphabet.json`, откройте папку `dist` через любой простой локальный веб-сервер. Например, если установлен Python, в корне проекта выполните:

```powershell
py -m http.server 4173 --directory dist
```

После этого перейдите по адресу `http://localhost:4173`.

## Публикация в интернете

Проект опубликован бесплатно через GitHub Pages: [valkinaz.github.io/armat](https://valkinaz.github.io/armat/). В публичном репозитории `valkinaz/armat` источником Pages выбран **GitHub Actions**.

Workflow `.github/workflows/deploy-pages.yml` автоматически публикует папку `dist` после каждого `git push` в `main`. Сайт будет доступен по адресу `https://valkinaz.github.io/armat/`.

## Добавить букву

Отредактируйте `dist/alphabet.json` и добавьте запись в том же формате:

```json
{ "upper": "Բ", "lower": "բ", "sound": "Б" }
```

`upper` и `lower` — заглавная и строчная формы; `sound` — произношение, которое будет показано на карточке и в вариантах ответа. После сохранения обновите страницу браузера.
